# WHSCalcExpo

This is an Expo React Native port of the golf handicap calculator (WHSCalcApp). It uses Material Design components from `react-native-paper` and the Expo-compatible `@react-native-picker/picker` for all UI. The app is designed for easy, modern, and mobile-friendly golf handicap calculations.

## Features
- Material Design UI (react-native-paper)
- Safe area and scrollable layouts
- Supports multiple golf formats (strokeplay, matchplay, pairs, scramble)
- Expo-compatible (runs on iOS, Android, and web)

## Getting Started
1. Install dependencies:
   ```powershell
   npm install
   ```
2. Start the Expo development server:
   ```powershell
   npx expo start
   ```
3. Open the app in Expo Go (mobile) or in your browser (web).

## Project Structure
- `App.js` - Main application file (replace with your ported App.tsx logic)
- `index.js` - Entry point
- `assets/` - App icons and splash images

## Customization
- All UI should use Material Design components from `react-native-paper`.
- Avoid any non-Expo-compatible native modules.
